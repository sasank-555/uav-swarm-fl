# B.Tech project report (NIT Warangal)

This folder will hold the LaTeX source for the semester project report. It will follow
the institute's *Guidelines for Preparation of B.Tech Report*:
- A4 paper, Times New Roman 12 pt, 1.5 line spacing, 30 mm left and 20 mm right margins
- Specimens A to D: title sheet, approval sheet, declaration, and certificate
- A 500-word abstract, then the contents, figure and table lists, and abbreviations
- Chapters: Introduction, Literature Review, method, Results and Discussion, Conclusions
- IEEE-style references

The report reuses the figures and numbers produced for [`../paper`](../paper/README.md),
so the two documents cannot disagree.
